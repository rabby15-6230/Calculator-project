# Changelog

All notable changes to this project will be documented here.

## [v1.1.0] - 2026-08-24
### Added
- Tkinter graphical user interface (gui.py) with button-based input,
  supporting basic and scientific operations

## [v1.0.0] - 2026-08-24
### Added
- Basic arithmetic operations: add, subtract, multiply, divide
- Scientific operations: power, sqrt, log, sin, cos
- Command-line interface (main.py) with argparse
- Manual smoke test script

### Fixed
- Removed stray debug print statement from add() (reverted)
